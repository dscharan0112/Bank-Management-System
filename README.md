# Bank Management System

A standalone C++ console-based Bank Management System developed for the Software Architecture and Design course.

## Features

- Customer account creation
- Customer login with PIN
- Balance inquiry
- Deposit
- Withdrawal
- Customer profile viewing
- Admin login
- View all customer accounts
- Freeze/unfreeze account
- Close account
- Account summary report
- Local file-based data persistence

## Technology

- C++
- Standard C++ Library
- Text-file based local persistence

## How to Run

### Linux / macOS

```bash
g++ main.cpp -o bank_management_system
./bank_management_system
```

### Windows (MinGW)

```bash
g++ main.cpp -o bank_management_system.exe
bank_management_system.exe
```

## Default Admin PIN

```text
9999
```

Change the admin authentication implementation before using the system beyond demonstration purposes.
